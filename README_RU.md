# MD Show 1.0

**Быстрый и компактный просмотрщик и редактор Markdown для Windows 11 x64.**

Программа работает с документами локально: без облачной учётной записи, отправки файлов на сервер и встроенного браузерного движка.

[**Скачать MD Show**](https://github.com/MonolitVladimir/MDShow/releases) · [English](README.md) · [Deutsch](README_DE.md) · [العربية](README_AR.md) · [简体中文](README_ZH-CN.md)

## Возможности

- Чтение, редактирование и разделённый экран с живым предпросмотром Markdown.
- Вкладки, оглавление, последние файлы, форматирование, продолжение списков.
- Таблицы GFM, задачи, блоки кода и локальные изображения.
- Поиск и замена, отмена/повтор, масштабирование и три темы оформления.
- Пять языков интерфейса: русский, английский, немецкий, арабский, китайский; Unicode и RTL.
- Сохранение кодировки, BOM и переводов строк; атомарная запись, предупреждения о конфликтах и восстановление черновиков.
- Экспорт HTML/PDF и печать.

## Загрузка и установка

Дистрибутивы доступны в разделе [GitHub Releases](https://github.com/MonolitVladimir/MDShow/releases).

| Файл | Назначение |
| --- | --- |
| `MDShow-1.0-Setup-x64.exe` | Установка для всех пользователей, пять языков, интеграция «Открыть с помощью» |
| `MDShow-1.0-portable-x64.zip` | Portable с пятью языками; распаковать ZIP целиком и запустить `MDShow.exe` |
| `MDShow-1.0-portable-en-x64.zip` | Portable с английским интерфейсом и поддержкой Unicode-документов |

**Требования:** Windows 11 x64, .NET Framework 4.8 и установленный Microsoft Edge WebView2 Evergreen Runtime. Установщик запросит права администратора. Portable не регистрирует файловые ассоциации. Windows 10 не входит в поддерживаемую конфигурацию.

**Цифровой подписи пока нет.** Проверяйте контрольные суммы файлов по `SHA256SUMS.txt` из релиза. Windows может предупреждать о неизвестном издателе; отключать защиту системы не нужно.

## Как пользоваться

Открывайте `.md` через **Файл → Открыть**, а в установленной версии — также через контекстное меню Windows «Открыть с помощью».

| Сочетание | Действие |
| --- | --- |
| `Ctrl+O`, `Ctrl+N` | Открыть или создать документ |
| `Ctrl+S`, `Ctrl+Shift+S` | Сохранить / Сохранить как |
| `Ctrl+1`, `Ctrl+2`, `Ctrl+3` | Редактор / две панели / чтение |
| `Ctrl+F`, `Ctrl+H` | Поиск / замена |
| `Ctrl+A`, `Ctrl+Z`, `Ctrl+Y` | Выделить текст активной области / отменить / повторить |
| `F1` | Список горячих клавиш |

## Данные и ограничения

Файлы не загружаются в облако. Внешние изображения заблокированы. Настройки и локальные черновики находятся в `%LOCALAPPDATA%\MDShow`; у установленной версии и обеих portable-версий независимые профили. Они **не зашифрованы** и не заменяют резервного копирования. Portable-профиль не хранится рядом с EXE.

Максимальный файл — **16 МиБ**. Для предпросмотра действует отдельный лимит входа **1 млн символов**, а также ограничения сложности. Большие документы с огромным количеством коротких строк могут временно замедлять работу редактора. Mermaid, LaTeX и плагины не поддерживаются. Подробности: [примечания к выпуску](RELEASE-NOTES-v1.0.md) и [безопасность](SECURITY.md).

Перед удалением установленной версии сохраните черновики и закройте программу во всех сеансах Windows. Удаление не стирает сохранённые документы, portable-профили или данные других пользователей. Профиль Installed текущего пользователя удаляется только при безопасном подтверждении его учётной записи.
