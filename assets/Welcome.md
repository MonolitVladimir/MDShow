# Welcome to MD Show 1.0

A lightweight Markdown viewer and editor for Windows 11.

Use **Ctrl+O** to open a document, **Ctrl+S** to save, and **F1** for shortcuts.
Switch between Editor, Split view and Read. Zoom the document from 50% to 300%
without enlarging the toolbar. The full edition offers five interface languages;
the English-only edition supports the same Unicode documents and editing tools.

## Try Markdown

- [x] Local editing and live preview
- [x] Outline, tabs, search and replace
- [x] PDF, HTML and print

External images are blocked. Local images must stay inside the document folder.
Draft recovery is local and unencrypted; keep an independent backup of important files.
