# MD Show 1.0.1

Просмотр и редактирование Markdown на Windows 11 x64. Нужны .NET Framework 4.8
и системный WebView2 Evergreen; браузерный движок не включён в пакет.
Setup добавляет «Открыть с помощью» и необязательное классическое меню Explorer.
Полная portable содержит пять языков; English-only — тот же функционал с
английским интерфейсом, без ограничений на язык документов.

Распакуйте весь ZIP и запустите MDShow.exe. Portable не создаёт ассоциации.

Настройки, недавние пути, recovery и кэш WebView2 разделены по вариантам:

- Установленная версия: `%LOCALAPPDATA%\MDShow\Installed`
- Полная portable: `%LOCALAPPDATA%\MDShow\PortableFull`
- English portable: `%LOCALAPPDATA%\MDShow\PortableEnglish`

Все три варианта можно запускать одновременно. IPC разделён по вариантам;
файловая блокировка исключает одновременную запись в один профиль из разных сессий.
Portable означает работу без установки, а не профиль рядом с EXE. Каталог программы
может быть доступен только для чтения.

Файлы старого общего `%LOCALAPPDATA%\MDShow` не переносятся и не удаляются.
Для ручного переноса закройте все варианты, сделайте копии старого и нового
профилей и скопируйте только `settings.json` в выбранный новый каталог.
English-only останется английским. Восстановленные черновики сначала сохраните
старой программой как обычные MD-файлы, затем откройте новой; не заменяйте новый
recovery старым. Кэш переносить не нужно. Если запуск заблокирован, дождитесь
окончания установки/удаления либо закройте экземпляр с этим профилем в другой
сессии. Повреждённую установку можно исправить повторным запуском Setup.

Ctrl+O — открыть, Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как, F1 — помощь.
Есть вкладки, оглавление, поиск/замена, три режима, темы, масштаб 50–300%,
GFM, PDF/HTML, печать, сохранение кодировки/переносов и восстановление черновиков.

Setup устанавливает программу для всех пользователей в C:\Program Files\MD Show
с правами администратора.
Перед удалением закройте MD Show во всех сессиях Windows. Установщик использует
файловую блокировку и Restart Manager и не завершает работающие процессы.
Деинсталлятор удаляет программу, регистрацию, настройки, кэш и recovery только
Installed-профиля подтверждённой учётной записи текущего сеанса. Очистка выполняется
без административных прав. Если UAC использует другую учётную запись, все профили
сохраняются с уведомлением. Ошибка безопасной очистки останавливает удаление до
удаления программы; часть кэша к этому моменту может быть очищена. Сохранённые MD-документы,
portable-профили, старые общие файлы и данные других пользователей остаются.
Нужные черновики предварительно сохраните.

Панель: «Файл» (Alt+F), дискета, поиск, режимы и масштаб; настройки — в меню «Файл».

Файл ограничен 16 МиБ; предпросмотр имеет дополнительные ограничения.
Внешние изображения запрещены. Гонки путей и параллельной записи сторонним
локальным процессом остаются ограничениями. Приложение не отправляет документы
на сервер. EXE/Setup без подписи; проверяйте SHA-256 и не обходите защиту Windows.
