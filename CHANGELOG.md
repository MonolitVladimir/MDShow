# Changelog

## [1.0.0] — 2026-11-03

First public release of MD Show for Windows 11 x64.

### Features

- Markdown reading, source editing and live split preview with tabs and document outline.
- GFM tables and tasks, local images, formatting, search/replace, zoom and themes.
- English, Russian, German, Arabic and Simplified Chinese UI; Unicode and RTL support.
- Encoding and line-ending preservation, conflict warnings, atomic saving and local recovery.
- HTML/PDF export and printing.
- Windows installer and two portable editions with separate local profiles.

### Reliability and performance

- Optimized application startup and initial document transfer.
- Keyboard focus and text selection behave within the active document or input.
- Improved early-close recovery handling and localized native dialogs.
- Multi-session installation/uninstallation safeguards preserve unrelated user files.

See [release notes](RELEASE-NOTES-v1.0.md) for requirements, security notes and known limitations.
