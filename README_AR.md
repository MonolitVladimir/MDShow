# MD Show 1.0 — دليل الاستخدام

[اللغات](README.md) · [English](README_EN.md) · [Русский](README_RU.md) · [Deutsch](README_DE.md) · [简体中文](README_ZH-CN.md)

## الوظائف والمتطلبات

قارئ ومحرر Markdown خفيف لنظام **Windows 11 x64**. يوفر وضع القراءة والتحرير
والعرض المنقسم مع معاينة مباشرة، وعلامات تبويب وفهرس عناوين وملفات حديثة،
وتنسيق النص ومتابعة القوائم والتراجع والإعادة والبحث والاستبدال النصي.
يدعم جداول GFM وقوائم المهام والشطب والشيفرة والصور المحلية، وتصدير HTML/PDF
ومعاينة الطباعة. لا يتضمن Mermaid أو LaTeX أو إضافات. Windows 10 خارج نطاق الدعم.

يتطلب ‎.NET Framework 4.8 و**Microsoft Edge WebView2 Evergreen المثبت في النظام**.
لا يضم محرك متصفح أو Electron أو بيئة Node، ولا يحتاج حسابًا أو رفع المستندات.
إذا كان WebView2 مفقودًا، استخدم توزيعه الرسمي من Microsoft.

## الحزم الثلاث

| الملف | الاستخدام |
|---|---|
| `MDShow-1.0-Setup-x64.exe` | تثبيت لجميع المستخدمين في Program Files بصلاحيات المسؤول؛ خمس لغات، «فتح باستخدام»، التطبيقات الافتراضية وأوامر مستكشف الملفات التقليدية الاختيارية |
| `MDShow-1.0-portable-x64.zip` | فك الحزمة كاملة وتشغيل `MDShow.exe`؛ واجهة بخمس لغات |
| `MDShow-1.0-portable-en-x64.zip` | وظائف المستندات نفسها مع موارد واجهة إنجليزية فقط |

نسخة English-only تدعم المستندات العربية والروسية والصينية والنص المختلط Unicode،
وتحافظ على اختيار اللغة المحفوظ للنسخة الكاملة. قد تتبع حوارات النظام لغة Windows.
الحزم المحمولة لا تسجل ارتباطات الملفات ولا تتضمن بيئة WebView2.

## التثبيت والإزالة

يثبّت Setup التطبيق لجميع المستخدمين في `C:\Program Files\MD Show` ويطلب صلاحيات
المسؤول. يمكن فك ZIP في مجلد قابل للكتابة دون تثبيت. اختر MD Show عبر «فتح باستخدام»
أو التطبيقات الافتراضية؛ لا يُفرض تغيير `UserChoice`. قد تظهر الأوامر التقليدية
تحت «إظهار المزيد من الخيارات».

أغلق MD Show في جميع جلسات Windows قبل الإزالة. يستخدم المثبت قفل ملف التثبيت
وRestart Manager ولا ينهي العمليات الجارية. تُحذف ملفات البرنامج وتسجيلاته
وإعدادات وذاكرة ومسودات ملف Installed للحساب المؤكد للجلسة الحالية فقط.
يتم التنظيف دون صلاحيات المسؤول. عند استخدام حساب آخر في UAC تُحفظ جميع ملفات
التعريف مع إشعار. إذا فشل التنظيف الآمن، تتوقف الإزالة قبل حذف ملفات البرنامج؛
قد يكون جزء من الذاكرة المؤقتة قد حُذف بالفعل. تبقى مستندات Markdown المحفوظة وملفات
النسخ المحمولة والملفات المشتركة القديمة وبيانات المستخدمين الآخرين.
احفظ المسودات المهمة أولاً.

يعرض الشريط الشعار و**ملف** والحفظ والبحث وأوضاع العرض والتكبير. تجمع قائمة ملف
أوامر الإنشاء والفتح والحفظ والتصدير والطباعة والإغلاق. تحتوي الإعدادات على السمة
والتفاف الأسطر واللغة والفهرس. يفتح Alt+F القائمة، وتتنقل الأسهم، ويغلقها Escape.

## الملف الشخصي والخصوصية

الإعدادات والمسارات الحديثة والاسترداد وذاكرة WebView2 منفصلة لكل نسخة:

- النسخة المثبتة: `%LOCALAPPDATA%\MDShow\Installed`
- النسخة المحمولة الكاملة: `%LOCALAPPDATA%\MDShow\PortableFull`
- النسخة المحمولة الإنجليزية: `%LOCALAPPDATA%\MDShow\PortableEnglish`

يمكن تشغيل النسخ الثلاث معاً. اتصال IPC منفصل لكل نسخة، ويمنع قفل الملف الكتابة
المتزامنة إلى الملف نفسه من جلسات متعددة. تعني portable عدم الحاجة إلى التثبيت،
ولا تعني وجود الإعدادات بجوار EXE. يمكن أن يكون مجلد البرنامج للقراءة فقط.


لا تُستورد ملفات `%LOCALAPPDATA%\MDShow` المشتركة القديمة ولا تُحذف تلقائياً.
للنقل اليدوي أغلق جميع النسخ، وانسخ الملفات القديمة والجديدة احتياطياً، ثم انسخ
`settings.json` فقط إلى المجلد الجديد المطلوب. تبقى الواجهة الإنجليزية إنجليزية.
احفظ المسودات المستردة في النسخة القديمة كمستندات Markdown عادية ثم افتحها في
الجديدة؛ لا تستبدل ملف الاسترداد الجديد. لا حاجة لنقل الذاكرة المؤقتة. إذا تعذر
التشغيل، انتظر انتهاء التثبيت أو الإزالة، أو أغلق الجلسة الأخرى التي تستخدم
الملف نفسه. يمكن إصلاح تثبيت تالف بإعادة تشغيل Setup.

تُحفظ المسودات كل نحو عشر ثوانٍ بصيغة JSON **غير مشفرة** تحت صلاحيات حساب Windows.
بعد التعطل يعرض التطبيق استعادتها؛ ليست بديلًا للنسخ الاحتياطي. عند تغيير الملف
خارجيًا يظهر طلب لحل التعارض؛ الإلغاء يحافظ على المسودة والملف الخارجي. تحمي
الكتابة الذرية من فشل استبدال الملف، لكنها ليست معاملة مشتركة مع البرامج الأخرى.

## العرض واللغات والترميز

الواجهة الكاملة: الإنجليزية والروسية والألمانية والعربية والصينية المبسطة.
الوضع التلقائي يتبع Windows مع الإنجليزية كخيار احتياطي؛ الاختيار اليدوي محفوظ.
الواجهة العربية RTL واتجاه المستند مستقل، والشيفرة والروابط والمسارات LTR.
تستخدم الصينية خطوط النظام البديلة. توجد سمة النظام والفاتحة والداكنة، وتكبير
المستند **50–300%** بأزرار الشريط أو Ctrl مع عجلة الفأرة. يُحفظ عرض اللوحتين.
تحتاج IME الصينية الحقيقية وقيم DPI الإضافية في Windows إلى الفحص اليدوي
المذكور في ملاحظات الإصدار.

يدعم UTF-8 مع/بدون BOM وUTF-16/32 مع BOM وWindows-1251. يحتفظ الحفظ بالترميز
وBOM ونهايات LF/CRLF/CR الأصلية. الأحرف غير القابلة للتمثيل تحتاج موافقة صريحة
على التحويل إلى UTF-8.

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+O / N; Ctrl+S / Ctrl+Shift+S` | فتح / جديد؛ حفظ / حفظ باسم |
| `Ctrl+W / Tab / Shift+Tab` | إغلاق التبويب / التالي / السابق |
| `Ctrl+1 / 2 / 3` | تحرير / عرض منقسم / قراءة |
| `Ctrl+F / H; Ctrl+B / I / K` | بحث / استبدال؛ عريض / مائل / رابط |
| `Ctrl+Z / Y; Ctrl+P; F1` | تراجع / إعادة؛ طباعة؛ مساعدة |
| `Ctrl++ / − / 0; Ctrl+wheel` | تكبير / تصغير / إعادة الضبط |

## الحدود والأمان

قد تستغرق معالجة المحرر وإمكانية الوصول في WebView2 وقتًا طويلًا عند فتح مستندات كبيرة تحتوي على عدد هائل من الأسطر القصيرة. انتظر اكتمال التحميل. هذا قيد مقبول للإصدار الأول؛ راجع RELEASE-NOTES-v1.0.md.

حد الملف **16 MiB**. المعاينة: **1 Mi محرف** مدخل و**2 Mi محرف** HTML، مع حد
للتعقيد ومهلة تقارب **1.5 ثانية** للعامل. قد تُرفض المعاينة المعقدة ويبقى المحرر متاحًا.
الصور الخارجية محظورة. الصور وروابط Markdown المحلية محصورة بمجلد المستند
وفروعه؛ تُرفض الوصلات الرمزية وjunction الموجودة في الفروع والمخططات غير الآمنة.
تفتح روابط http/https/mail المطلوبة صراحةً خارج التطبيق.

يمكن لعملية محلية أخرى تبديل مسار بين فحصه وفتحه (TOCTOU)، أو الكتابة بين فحص
التعارض والحفظ. هذه الحدود موثقة ولم تُلغَ. حدّث Windows/WebView2؛ انظر
[SECURITY.md](SECURITY.md). أبلغ عن الثغرات عبر [قناة GitHub الخاصة](https://github.com/MonolitVladimir/MDShow/security).
لا تنشر مستندات خاصة أو تفاصيل استغلال في المشكلات العامة.

EXE وSetup **غير موقّعين**؛ قد يحذّر SmartScreen. لا تتجاوز وسائل الحماية.
قارن SHA-256 بملف المجاميع المقدم منفصلًا:

</div>

```powershell
Get-FileHash .\MDShow-1.0-portable-x64.zip -Algorithm SHA256
```

## البناء من المصدر

يتطلب البناء Windows 11 x64 و.NET Framework 4.8 وPowerShell 7.
تُحمَّل التبعيات الضرورية مع التحقق من بصماتها.

</div>

```powershell
pwsh -File scripts/bootstrap.ps1 -Installer
pwsh -File scripts/build.ps1 -Installer
```

<div dir="rtl">

تُنشأ الملفات في `dist/`. لا يُضمن تطابق النتائج على مستوى البايت.
يمكن إعادة توليد الرموز اختيارياً باستخدام `scripts/make-icon.ps1` مع Python/Pillow 12.2.0.
